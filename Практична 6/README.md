# Практична робота №6. Реляційна алгебра: формалізація запитів і встановлення еквівалентностей

**Предмет:** Бази даних  | **Група:** ІПЗ-41  | **Виконала:** Єва Якимчук

## Вхідні відношення
`S = Студенти(№, Прізвище, Група)`, `C = Курси(Код, Назва)`, `G = Успішність(№, Код, Оцінка)`. З'єднання позначаємо `⋈_{умова}`, вибірку — `σ`, проєкцію — `π`.

## 1. Три запити
**Прізвища студентів групи 121** (вибірка та проєкція):

`π_{Прізвище}(σ_{Група=121}(S))`

**Назви курсів студента №101** (вибірка, з'єднання, проєкція):

`π_{Назва}((σ_{№=101}(G)) ⋈_{G.Код=C.Код} C)`

**Пари «студент — оцінка» з оцінкою >80** (вибірка, з'єднання, проєкція):

`π_{S.Прізвище, G.Оцінка}(S ⋈_{S.№=G.№} σ_{Оцінка>80}(G))`

Проєкція в класичній алгебрі усуває дублікати; для повторюваних прізвищ у реальній системі краще додати `№` до проєкції.

## 2. Еквівалентність і просування селекції
Для курсів студента №101:

**До:** `E1 = π_{C.Назва}(σ_{G.№=101}(G ⋈_{G.Код=C.Код} C))`.

**Після:** `E2 = π_{C.Назва}((σ_{G.№=101}(G)) ⋈_{G.Код=C.Код} C)`.

**Доведення:** предикат `G.№=101` залежить лише від `G`. Тому кожний рядок з'єднання проходить умову тоді й тільки тоді, коли пройшов її рядок `G` перед з'єднанням. `E1=E2`. Другий вираз може потребувати менше проміжних рядків. Також еквівалентність сполучення за однаковою умовою демонструє комутативність `G ⋈ C = C ⋈ G` за узгоджених назв атрибутів.

## 3. Ручна перевірка (4, 3, 4 рядки)
**S**
| № | Прізвище | Група |
|---|---|---|
| 101 | Іваненко | 121 |
| 102 | Петренко | 121 |
| 103 | Шевчук | 122 |
| 104 | Коваль | 123 |

**C**
| Код | Назва |
|---|---|
| DB | Бази даних |
| WEB | Вебтехнології |
| ALG | Алгоритми |

**G**
| № | Код | Оцінка |
|---|---|---|
| 101 | DB | 90 |
| 101 | WEB | 75 |
| 102 | ALG | 85 |
| 103 | DB | 78 |

Результати:
- група 121 → `{Іваненко, Петренко}`;
- курси студента 101 → `{Бази даних, Вебтехнології}`;
- студент — оцінка >80 → `{(Іваненко, 90), (Петренко, 85)}`.

**E1:** спочатку з'єднання 4 рядків `G` з `C` — 4 збіги, відбір №101 — 2, проєкція — 2 назви. **E2:** спочатку 2 рядки `G` з №101, з'єднання з `C` — 2, проєкція — ті ж 2 назви. Це підтверджує еквівалентність на прикладі, а загальне доведення наведено вище.

## Питання для захисту
1. Проєкція залишає лише задані атрибути, у множинній семантиці видаляє дублікати.
2. З'єднання — добуток із умовою зіставлення; декартовий добуток формує всі комбінації.
3. Рівносильні перестановки з'єднання/селекції можуть зменшити проміжний результат.
4. Селекцію можна перенести перед з'єднанням, коли предикат використовує атрибути лише однієї сторони та збережено семантику з'єднання (тут INNER JOIN).


## Висновок
Розглянуто три запити та еквівалентні перетворення. На невеликих наборах даних обидві форми дали однакові результати.
